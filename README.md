# mingikim1.github.io

Personal academic website of Mingi Kim, live at https://mingikim1.github.io.

Built from [Jon Barron's website template](https://github.com/jonbarron/jonbarron_website): a single static `index.html` plus `stylesheet.css`. To add a paper, copy one of the `<tr>` blocks in `index.html` and put its thumbnail in `images/`.
